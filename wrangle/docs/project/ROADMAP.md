# Researcher roadmap: October 2026–September 2027

This is the intended direction, not a promise of a particular delivery date.
Scope decisions and progress are recorded in issues and release notes.

## October–December 2026

Publish the native Polars migration with its verified human/agent workflows.
Trial guided protocol drafting with real researchers, using consented or
synthetic datasets. Use the findings to improve plain-language questions,
uncertainty handling and recovery without guessing scientific meaning.
Establish measured coverage, dependency/security scans, signed release evidence
and a verified backup maintainer before claiming Best Practices silver.

## January–March 2027

Improve common instrument and spreadsheet workflows where researcher trials
show missing capabilities. Preserve identifiers, numeric precision, source units
and observation identity. Keep the recipe vocabulary small; extend operations
only when an actual study needs them. Review repeat-batch and frozen-parameter
workflows against practical failures.

## April–June 2027

Reduce memory and I/O cost in guided inspection and disk preparation where
measurements show a bottleneck. Preserve input snapshots, order, checked join
cardinality, complete exclusions and atomic publication. Report measured resource
limits; do not claim fixed memory bounds for stateful native operations.

## July–September 2027

Review the human/agent manual, examples and migration path with users. Improve
accessibility and evaluate localization needs. Rehearse maintainer continuity,
review release verification and dependency support, and remove documented
friction that blocks everyday researcher work.

## Boundaries throughout the year

No neural-network construction, model training, arbitrary Python callbacks in
recipes, inferred scientific units or exclusions, silently changed statistical
methods, or evidence-free preparation. Keep `inspect` and `prepare` as the public
recipe entrypoints. CLI and Python must continue to share native Polars execution
and research contracts; badges report evidence rather than change package scope.
